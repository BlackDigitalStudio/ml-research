## Словарь

| термин | значение |
|---|---|
| **bp** | базисный пункт = 0.01%. EV +30bp = +0.30% на сделку до плеча |
| **EV/сделку** | средний чистый результат сделки после комиссий (4bp/круг), в bp от номинала |
| **член (ансамбля)** | одна обученная XGBoost-модель (пара A×B), скорящая каждое 3-секундное решение |
| **сид** | член, отличающийся только случайным зерном поиска гиперпараметров |
| **RF-член** | член по рецепту random forest: случайная подвыборка фич (−25%) + бэггинг обучающих дней (63.2%) + свой сид |
| **фич-подвыборка** | член обучен без случайных ~14 из 56 живых колонок-признаков |
| **бэггинг данных** | член обучен на случайных 63.2% обучающих дней каждого фолда |
| **протокол v1 / v2** | подбор гиперпараметров: v1 = последовательный TPE (Optuna), v2 = детерминированный Sobol; случайность поиска — источник разнообразия членов |
| **без OI-фич** | исключены дельты open interest (на Bybit только 5-минутные — шум для этих ячеек) |
| **без time-of-day** | исключены признаки часа/фандинг-цикла: на LTC вредят, на 1000PEPE — несущие |
| **отбор T сигн./день** | член пропускает только топ-скоры: скользящий причинный порог на ~T сигналов в день |
| **union** | сделка = хотя бы один член дал сигнал; направление — большинство сигналивших |
| **консенсус ≥k** | сделка = не менее k членов сигналят одновременно; строже согласие → реже и точнее |
| **усреднение скоров** | классический ансамбль (среднее скоров, порог по среднему); комиссии его убивают — в таблице почти нет |
| **hit** | доля прибыльных сделок |
| **F10** | размер позиции (× капитала), при котором P(просадка>25%)≤10% по 1000 бутстреп-сценариев |
| **ROI25 / p10** | доходность %/мес при F10 / худший дециль бутстреп-сценариев — все формы на одном риске |
| **ROI мес (F=1)** | доходность без плеча, 100% капитала в сделке, реинвестирование |
| **maxDD** | максимальная просадка реализованного пути при F=1 |
| **Sharpe / Sortino** | дневная доходность / волатильность (Sortino — только вниз), годовые |
| **Calmar** | годовой ROI / maxDD; годовой ROI — экстраполяция, Calmar оптимистичен |
| **фолд** | один из 7 последовательных ~месячных тестовых отрезков; «—» = не было сделок |
| **LOFO-min** | EV/сделку при выбросе лучшего фолда — защита от «один удачный месяц» |
| **p80 / upow** | p80: выборки хватает для подтверждения эджа этого размера с мощностью 80% (SE≤EV/2.49); upow — гейт пройден, но статистики для такого эджа мало |
| **бутстреп** | 1000 пересборок теста из 7-дневных блоков — разброс всех метрик |
