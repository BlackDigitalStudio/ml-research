## Примечания

- **ПЕРЕКРЫТИЕ ПОЗИЦИЙ (rev24, 2026-08-08): F10/ROI25 в таблице НЕ реализуемы буквально для кластеризованных форм.** Батарея DD-25 компаундирует сделки последовательно, что честно только при почти нулевом перекрытии. Измерение (overlap probe): сигналы живут в редких плотных бёрстах (в рынке 0.1-0.2% времени), и при размере F10 на каждую сделку валовая экспозиция достигает: rf32 cons T5 k≥8 при F0.58 — в среднем 10× капитала на входе, p95 24×, max ~30× (пессимистично 50×); портфель invvol при F3.33 — в среднем 21×, max 86× (выше максимального плеча Bybit 75×). Бёрст-сделки консенсуса одной стороны ⇒ это направленное плечо; дневной бутстреп такой внутрибёрстовый риск не видит. Также эффективное число независимых решений ~50-90 бёрст-эпизодов, а не 817/2122 сделок — порог n≥100 для таких форм завышает выборку.
- **Реализуемые цифры (rev24b, кап валовой экспозиции C, артефакты HBV1_OVERLAP_CAPPED_*)**: при капе исполнение вырождается в ~одну позицию размера C на бёрст, ROI25 линеен по C. RF-лес-32 консенсус ≥8: **≈ +3.4%/мес на 1× капитала** (C=1: +3.4%, p10 +1.6%; C=3: +10.1%; Sharpe 3.11); просадочный бюджет DD-25 связывает только при C≈7.2 → **потолок +23.8%/мес, p10 +10.3%**. Портфель invvol-7: ≈ +2.3%/мес на 1× (потолок при C≈8.6 → +20.4%/мес, p10 +5.7%, Sharpe 2.62). **Инверсия**: при честном исполнении одиночный rf32 доминирует портфель — формы портфеля штабелируются в одни и те же бёрсты, его «диверсификация» была в основном скрытым плечом. Прежние ROI25 таблицы завышены ~×2 для кластеризованных форм. Из-за концентрации бюджета в ~один ордер на бёрст (номинал ордера = C × капитал) масштабирование капитала упирается в неизмеренную кривую ёмкости (см. ниже) раньше, чем в маржу.
- **Ёмкость НЕ ИЗМЕРЕНА** (коррекции capacity-unmeasured-20260717 и hbv1 rev23): fill-симуляция честна в пределе малого собственного размера (модель «всегда последние в очереди», без смещения книги); живые измерения велись на номинале $10-25; кривая EV-vs-размер никогда не мерилась. Формы с F10>5-10 дополнительно упираются в неизмеренный хвостовой риск плеча.
- **1000PEPE**: целевой ансамбль даёт углы с hit 89-94% (EV +58…+73bp), но n=17-36 — ниже пола выборки; в таблице отсутствует. Следующий шаг — масштаб числа членов.
- **LTC**: единственная валидная форма (консенсус ≥4) — upow: эджу +39bp нужно ~300+ сделок, накоплено 104; её F10=11 за пределами разумного плеча — оперируйте F≈2-3 (~+25-30%/мес).
- Репликация дро (8 непересекающихся 4-членных RF-пулов): union 0.63/д — среднее +33.0bp, sd ±17.9bp, гейт проходят 4/8. Малые пулы — лотерея одного набора; крупный консенсус усредняет.
- Грид-селекция ограничена гейтом, но не устранена; зимний бёрст-фолд (f2) везде даёт максимальную плотность сделок; одна ячейка «символ × год».

## Словарь

| термин | значение |
|---|---|
| **bp** | базисный пункт = 0.01%. EV +30bp = +0.30% на сделку до плеча |
| **EV/сделку** | средний чистый результат сделки после комиссий (4bp/круг), в bp от номинала |
| **член (ансамбля)** | одна обученная XGBoost-модель (пара A×B), скорящая каждое 3-секундное решение |
| **сид** | член, отличающийся только случайным зерном поиска гиперпараметров |
| **RF-член** | член по рецепту random forest: случайная подвыборка фич (−25%) + бэггинг обучающих дней (63.2%) + свой сид |
| **фич-подвыборка** | член обучен без случайных ~14 из 56 живых колонок-признаков |
| **бэггинг данных** | член обучен на случайных 63.2% обучающих дней каждого фолда |
| **протокол v1 / v2** | подбор гиперпараметров: v1 = последовательный TPE (Optuna), v2 = детерминированный Sobol; случайность поиска — источник разнообразия членов |
| **без OI-фич** | исключены дельты open interest (на Bybit только 5-минутные — шум для этих ячеек) |
| **без time-of-day** | исключены признаки часа/фандинг-цикла: на LTC вредят, на 1000PEPE — несущие |
| **отбор T сигн./день** | член пропускает только топ-скоры: скользящий причинный порог на ~T сигналов в день |
| **union** | сделка = хотя бы один член дал сигнал; направление — большинство сигналивших |
| **консенсус ≥k** | сделка = не менее k членов сигналят одновременно; строже согласие → реже и точнее |
| **усреднение скоров** | классический ансамбль (среднее скоров, порог по среднему); комиссии его убивают — в таблице почти нет |
| **hit** | доля прибыльных сделок |
| **F10** | размер позиции (× капитала), при котором P(просадка>25%)≤10% по 1000 бутстреп-сценариев |
| **ROI25 / p10** | доходность %/мес при F10 / худший дециль бутстреп-сценариев — все формы на одном риске |
| **ROI мес (F=1)** | доходность без плеча, 100% капитала в сделке, реинвестирование |
| **maxDD** | максимальная просадка реализованного пути при F=1 |
| **Sharpe / Sortino** | дневная доходность / волатильность (Sortino — только вниз), годовые |
| **Calmar** | годовой ROI / maxDD; годовой ROI — экстраполяция, Calmar оптимистичен |
| **фолд** | один из 7 последовательных ~месячных тестовых отрезков; «—» = не было сделок |
| **LOFO-min** | EV/сделку при выбросе лучшего фолда — защита от «один удачный месяц» |
| **p80 / upow** | p80: выборки хватает для подтверждения эджа этого размера с мощностью 80% (SE≤EV/2.49); upow — гейт пройден, но статистики для такого эджа мало |
| **бутстреп** | 1000 пересборок теста из 7-дневных блоков — разброс всех метрик |
