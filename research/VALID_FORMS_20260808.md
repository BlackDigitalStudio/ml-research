## Примечания

- **1000PEPE**: целевой ансамбль (6 членов, без токсичных флоу-фич, горизонт h240) даёт консенсус-углы с hit 89-94% и EV +58…+73bp, но n=17-36 сделок — ниже пола выборки; в таблицу не включены. Следующий шаг — масштаб числа членов.
- **LTC**: строгий консенсус ≥5 (n=40) — тоже ниже пола. Единственная валидная форма LTC в таблице (консенсус ≥4) помечена upow: floor>0 есть, но для эджа +39bp нужно ~300+ сделок, накоплено 104.
- ROI25 у LTC-формы достигается плечом F11 — за пределами capacity-диапазона симуляции ($10-1k номинала); оперируйте строкой при F≈2-3 (~+25-30%/мес).
- 8 непересекающихся 4-членных RF-дро (репликация): union 0.63/д — среднее +33.0bp, sd ±17.9, 4/8 проходят гейт. Малые пулы — лотерея одного дро; 32-членный консенсус эту вариативность усредняет.

## Словарь

| термин | значение |
|---|---|
| **bp** | базисный пункт = 0.01%. EV +30bp = +0.30% на сделку до плеча |
| **EV/сделку** | средний чистый результат одной сделки после комиссий (4bp/круг), % от номинала позиции |
| **член (ансамбля)** | одна обученная XGBoost-модель (пара моделей A×B), дающая скор каждому 3-секундному решению |
| **сид** | член, отличающийся только случайным зерном поиска гиперпараметров |
| **RF-член** | член, обученный по рецепту random forest: случайная подвыборка фич (−25%) + бэггинг обучающих дней (63.2%) + свой сид |
| **фич-подвыборка (фич-бэг)** | член обучен без случайных ~14 из 56 живых колонок-признаков |
| **бэггинг данных (дата-бэг)** | член обучен на случайных 63.2% обучающих дней каждого фолда |
| **протокол v1 / v2** | способ подбора гиперпараметров: v1 = последовательный TPE (Optuna), v2 = детерминированный Sobol. Результаты эквивалентны, «случайность» поиска — источник разнообразия членов |
| **без OI-фич (no-OI)** | из признаков исключены дельты open interest (на Bybit доступны только 5-минутные — шум для этой ячейки) |
| **без time-of-day (noToD)** | исключены признаки часа суток/фандинг-цикла (sin/cos): на LTC они вредят, на PEPE — несущие |
| **отбор T сигн./день** | каждый член пропускает только свои топ-скоры: скользящий причинный порог, настроенный на ~T сигналов в день |
| **union** | сделка = хотя бы ОДИН член дал сигнал; направление — большинство сигналивших |
| **консенсус ≥k** | сделка = не менее k членов дали сигнал одновременно; строже согласие → реже и точнее |
| **усреднение скоров** | классический ансамбль: скоры членов усредняются, порог по среднему (комиссии его убивают — в таблице почти нет) |
| **hit** | доля прибыльных сделок |
| **сд/день** | сделок в календарный день теста |
| **ROI мес (F=1)** | доходность %/мес при 100% капитала в каждой сделке, последовательное реинвестирование, БЕЗ плеча |
| **ROI25 @F10** | доходность %/мес при размере позиции F10× капитала, где F10 подобран так, что P(просадка>25%)≤10% по 1000 бутстреп-сценариев — все формы приведены к одному риску |
| **ROI25 p10** | худший дециль бутстреп-сценариев при F10 — «нижняя планка» месячной доходности |
| **maxDD** | максимальная просадка капитала на реализованном пути (при F=1) |
| **Sharpe / Sortino** | средняя дневная доходность / её волатильность (Sortino — только волатильность вниз), годовые |
| **Calmar** | годовой ROI / maxDD (годовой ROI — экстраполяция, поэтому Calmar оптимистичен) |
| **фолд** | один из 7 последовательных ~месячных тестовых отрезков walk-forward; EV по фолдам показывает равномерность эджа во времени; «—» = в фолде не было сделок |
| **LOFO-min** | EV/сделку при выбросе ЛУЧШЕГО фолда — защита от «всё сделал один удачный месяц» |
| **гейт** | форма валидна если: 0 отрицательных фолдов ∧ LOFO-min>25% EV ∧ бутстреп-floor>0 ∧ n≥100 ∧ сделки в ≥5/7 фолдов |
| **p80 / upow** | p80: выборки хватает, чтобы эдж этого размера подтверждался с мощностью 80% (SE≤EV/2.49); upow — гейт пройден, но выборка мала для такого эджа: добор статистики до деплоя |
| **бутстреп** | 1000 пересборок года из случайных 7-дневных блоков — оценка разброса всех метрик |
