The deployed DOGE model trained on **Cryptolake** but must trade on our **live recorder** (chronos, Tokyo VM). They record the SAME Binance market bit-for-bit (top-of-book 99.9%, L0/L5 sizes 99.8% at matched exchange-ts), BUT the packaging differs:
- **CL book = event-driven ~1.3-2/s** (infra-timed by cl's collector, IRREPRODUCIBLE — kept-set Jaccard 0.08 vs any content rule; NOT clock/L0/trade-aligned). Recorder = uniform ~9/s. cl's own docs claim "100ms" but that's the burst rate; the daily average is ~1.3-2/s. What's in our GCS `raw/book` IS cl's actual product (not our downsampling).
- **CL trades are 3× triplicated** (dedup by (id,timestamp)) and are aggTrade; recorder = individual @trade + (after fix) aggTrade. Pipeline did NOT dedup → trade count/volume/rate features were 3× off.
- Recorder initially MISSED mark/funding/liquidations (Binance WS delivered 0 frames — a subscription bug since markPrice@1s streams continuously; parallel recorder agent restored it ~2026-07-01).

**Root cause:** `feature_builder` used TICK-based windows (300/600/1200 ticks labelled 30/60/120s, assuming ~10/s) → realized_vol/momentum were sampling-density-dependent. vol-gate A puts 47% of gain on realized_vol [37,38] → mis-fired on the dense recorder: pA corr 0.47, AxB-score 0.41, decision Jaccard 0.00 (= broken/random live).

**Plan A (use CL's long history NOW, don't wait weeks to accumulate recorder data):** make features sampling-robust + retrain on CL. DONE so far — `rust_ingest/src/features.rs` fill_horizon_features: realized_vol [37,38] + momentum [34,35,36] → fixed **1-second time grid** (returns over equal wall-clock). Cross-source feature drift (median |dX|/std) 1.4→0.26 (RV), 0.39→0.00 (momentum). Bipower [39] kept TICK (1s-grid forward-fill over cl gaps made it worse 0.56→1.63). Validated: edge preserved (AxB t5 +3.40→+3.11, t10 +1.65→+2.55, gate AUC identical) AND transfer up (pA 0.47→0.81, score 0.41→0.73, Jaccard 0.00→0.14). New binary `/tmp/fb_target/release/feature_builder`; robustvol labels `research_runs/maker_labels_pegexit_qm1_robustvol/DOGE.npz`; bundle `research_runs/deploy_robustvol/DOGE`. Splice tool: subs60_splice_vol.py (recompute changed cols by decision-ts, keep labels).

REMAINING to push transfer past Jaccard 0.14: [10,21,23] vol-family (same 1s-grid), **dedup CL trades ×3** (trade feats 7,8,22,48), OFI-sums (hard — don't fix with time-windows). Longer term = train on recorder once ~months accrue. See [[recorder-vm-live]], [[recorder-deploy-mechanics]].
